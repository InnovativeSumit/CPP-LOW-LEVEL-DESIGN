## 🎯 Repository Objective

The goal of this repository is to:
- Strengthen **Low Level Design skills**
- Apply **Object-Oriented Programming (OOP)** principles in C++
- Practice **real-world system design problems**
- Write **clean, maintainable, and extensible code**

Ideal for **students, interview candidates, and C++ developers**.

## 🧠 Concepts Covered

### 🔹 Core OOP Principles
- Encapsulation  
- Abstraction  
- Inheritance  
- Polymorphism  

### 🔹 Design Principles
- SOLID Principles  
- DRY & KISS  
- Composition over Inheritance  

### 🔹 Design Patterns
- Singleton  
- Factory & Abstract Factory  
- Strategy  
- Observer  
- Decorator  
- Builder  

## 🏗️ Low Level Design Problems

This repository includes LLD implementations such as:

- 🅿️ Parking Lot System  
- 🏦 Banking System  
- 🎬 Movie Ticket Booking System  
- 🚕 Ride Sharing System  
- 📚 Library Management System  
- 🛒 E-commerce Cart System  

Each design focuses on:
- Class diagrams → Code mapping  
- Interface-based design  
- Extensibility & scalability
